# 0046. Broadcast encoding: Opus in Ogg, with libopus

Status: accepted (M5).

## Context

Broadcasting sends the mix to a streaming server (`docs/behavior/broadcasting.md`). Sound must
be compressed for that: raw stereo at 48 kHz is about 1.5 Mbit/s. Writing a perceptual encoder is
far beyond the project for now, so an encoder is needed. The free MP3 encoder, LAME, is under the
LGPL, which Platter does not link (`AGENTS.md`, *Closed decisions*, *Licence*).

## Options

- **Opus** through the `opus` crate 0.4.0 (MIT OR Apache-2.0), which builds libopus from its
  source with `opusic-sys` 0.7.7 (BSD-3-Clause; libopus BSD-3-Clause, with royalty-free patent
  licences listed in its `COPYING`). It needs cmake and a C compiler at build time.
- **Vorbis** through `vorbis_rs` (BSD-3-Clause), a C library too, with an older codec.
- **FLAC** through `flacenc` (Apache-2.0), in Rust: lossless, so several times the bandwidth.
- **Opus in Rust**, `opus-rs` (BSD-3-Clause): its README calls it generated by a language model,
  and it has no independent review.
- **MP3 in Rust**, `rusty_mp3` (Apache-2.0): months old, no review.

## Choice

Opus with libopus, chosen by the maintainer on 22 November 2026. The `opus` crate is confined to
the module `stream` of a new crate, `platter-broadcast` (L1), where none of its types leaves.
The project writes the rest: the Ogg pages (RFC 3533), the Opus headers and granule positions
(RFC 7845) and the resampling to 48 kHz.

Every build now needs cmake and a C compiler; `docs/development.md` lists them. On Windows the
build of libopus goes through MSBuild, which fails when its paths pass 260 characters: a
checkout in a deep folder needs a shorter `CARGO_TARGET_DIR`.

A binary that is distributed carries libopus, whose BSD licence asks that its copyright notice
and licence travel with it (`docs/legal-notes.md`).

## How it was measured

`cargo test -p platter-broadcast`: a sine of 1 kHz at 44.1, 48 and 96 kHz, coded at 128 kbit/s,
read back and decoded with libopus, keeps its frequency within 3 Hz, its level within 0.02 and its
length to the frame. `cargo deny check` passes. Nothing was listened to.
