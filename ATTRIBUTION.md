# Attribution

Every resource in this repository (font, icon, image, audio file, data set) and every piece of
code adapted from another project has a row here. A resource without a row does not enter the
repository; `cargo xtask cleanroom` enforces this for audio files.

External crates are not listed here: they are in `docs/dependencies.md`.
